# Quantum Experience · เรียนควอนตัม.com

Interactive bilingual (Thai / English) quantum-science lab site for Thai high-school students, built by students in the SCIUS BUU program.

Live: https://เรียนควอนตัม.com/

This is an independent student project. It is not an official project of KMIDS or KMITL.

## Stack

Static HTML/CSS/JS served by nginx in Docker. Open `index.html` through any static server (for example `python3 -m http.server`) to run it locally.
